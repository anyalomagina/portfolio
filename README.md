# Anna Lomagina Portfolio Site

One-page portfolio site for Anna Lomagina: Product Content Writer / UX Writing / Healthcare Communication.

## Как открыть

Открой файл `index.html` в браузере.

## Что заменить

- Можно добавить ссылку на готовый PDF-резюме.
- Можно добавить реальные кейсы, когда они будут оформлены.
- Можно заменить телефон, если не хочется показывать его на публичном сайте.

## Как выложить

1. Создай репозиторий на GitHub.
2. Загрузи туда файлы `index.html`, `styles.css` и `README.md`.
3. На Vercel выбери этот репозиторий и нажми Deploy.
